# Legacy v2 integration

This section is for existing integrations that have not moved to the v1 contracts. It describes public client behavior only. New integrations should use the v1 guides.

Keep the legacy SDK and contract version together. Do not mix a legacy request signer or message schema with a v1 endpoint. Ask the RelayHub operator for the supported migration path before changing a production client.
