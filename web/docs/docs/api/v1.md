# v1 API reference

Use the product guides for the workflow and the machine-readable contracts for exact request and response fields.

| Task | Endpoint |
| --- | --- |
| Publish an event | `POST /api/v1/events` |
| Inspect an event | `GET /api/v1/events/{eventID}` |
| Receive a webhook | `POST /hooks/{endpointID}` |
| Request browser access | `POST /api/v1/socket/token` |
| Connect a durable worker | `GET /api/v1/stream` |

Accepted events return an event and delivery identity. Acceptance is separate from downstream completion. Use the delivery status and event timeline for the final outcome.

## Contract resources

[Download the OpenAPI contract](/openapi.json) and [message schemas](/asyncapi.yaml). Limits, errors, idempotency and authentication are part of the versioned contract.

Internal service endpoints are not customer integration APIs and are not included here.
