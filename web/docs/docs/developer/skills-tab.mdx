# SDKs and AI agents

Choose an SDK for application code or give your coding agent the integration Skill and contracts. These are separate downloads.

## TypeScript SDK

[Download TypeScript SDK source](https://relayhub.dungxbuif.com/docs/downloads/relayhub-typescript.zip).

The archive includes source, tests, package metadata and build scripts. It requires Node.js 20 or later.

```bash
curl -fL https://relayhub.dungxbuif.com/docs/downloads/relayhub-typescript.zip -o relayhub-typescript.zip
unzip relayhub-typescript.zip
cd relayhub-typescript
npm ci
npm run build
npm pack
```

Install the generated package with `npm install /path/to/package.tgz`. Use `@relayhub/sdk/node` for trusted backends and `@relayhub/sdk/browser` for token-authenticated clients.

## Go SDK

[Download Go SDK source](https://relayhub.dungxbuif.com/docs/downloads/relayhub-go.zip).

The archive includes the module, source and tests. Its module declares Go 1.27.1. Extract it alongside your project and configure the local module path:

```bash
go mod edit -replace github.com/dungxbuif/RelayHub/sdks/go=../relayhub-go
go get github.com/dungxbuif/RelayHub/sdks/go
```

Adjust the path to your extracted directory. Import `github.com/dungxbuif/RelayHub/sdks/go` from application code.

## Give an agent a starting point

Download the [integration Skill ZIP](/skills/relayhub-integration.zip) and read [SKILL.md](https://relayhub.dungxbuif.com/skills/relayhub-integration/SKILL.md). It contains instructions, authentication guidance and an OpenAPI snapshot. It is not an application SDK.

Suggested task:

> Read RelayHub's public guide and API contracts. Help integrate my application using credentials from local secret storage. Choose delivery based on whether I need durable work, live messages or a response. Keep secrets out of examples and logs. Verify one complete send-and-receive flow.
