# RelayHub Docusaurus Docs

Đây là track tài liệu đẹp (Docusaurus) cho team người dùng, dev và operator.

## Chạy local

```bash
cd docs-site
npm install
npm run start
```

- Docs site mặc định chạy tại `http://localhost:3000`.
- Đây là track trình bày, không thay đổi contract runtime.

## Sync với public-docs

Contract gốc vẫn là:
- `public-docs/openapi.json`
- `public-docs/llms.txt`
- `public-docs/llms-full.txt`
- `public-docs/skills/relayhub-integration.zip`

Cập nhật `public-docs` trước sau đó cập nhật nội dung Docusaurus cho cùng ý nghĩa.
