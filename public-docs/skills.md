# Skills Pack

The RelayHub integration Skill teaches API discovery, secure credential handling,
exact HMAC signing, events, queues/ack, callbacks/retries, WebSocket/reconnect and
remote functions. It uses standard HTTP/WebSocket libraries; no SDK is shipped.

[Open the Skills console with copy controls](index.html#skills), or
[download the integration ZIP](skills/relayhub-integration.zip).

- [Copyable SKILL.md](skills/relayhub-integration/SKILL.md).
- [Authentication reference](skills/relayhub-integration/references/authentication.md).
- [Bundled OpenAPI](skills/relayhub-integration/references/openapi.json).
- [Canonical deployed OpenAPI](openapi.json).

Extract the ZIP to an appropriate skills directory for your agent tool, keeping
`relayhub-integration/SKILL.md` and `references/` together. Follow your tool's
installation policy. Review instructions before granting credentials or actions.
The pack contains no secrets; supply credentials from your approved secret store.
The deployed docs describe that deployment; a downloaded pack remains a snapshot.
